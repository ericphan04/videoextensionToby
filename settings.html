Connect an MCP client
  1. Copy the token created above.
  2. Open Claude Desktop → Settings → Developer → Edit Config.
  3. Paste the configuration below, replace <token>, then restart Claude.
{ "mcpServers": { "tobyflow": { "command": "npx", "args": ["-y", "mcp-remote", "https://mcp.labs.toby.vn/mcp", "--header", "Authorization:Bearer <token>"] } } }
  1. Copy the token created above.
  2. Save it as the TOBYFLOW_MCP_TOKEN environment variable.
  3. Paste the configuration below into ~/.codex/config.toml, then restart Codex.
Terminal — set token for this session
export TOBYFLOW_MCP_TOKEN='<token>'
Codex config — ~/.codex/config.toml
[mcp_servers.tobyflow] url = "https://mcp.labs.toby.vn/mcp" bearer_token_env_var = "TOBYFLOW_MCP_TOKEN" enabled = true

Verify after restarting: run codex mcp list or enter /mcp in Codex.
